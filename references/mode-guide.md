# Mode guide

## Fast Track
Use by default when:
- the business is understandable enough
- the user wants a practical result fast
- the goal is to package an agency or service offer into a landing without turning it into a long workshop

## Deep Positioning
Use only when:
- audience is unclear
- market angle is fuzzy
- offer sounds generic
- stronger differentiation work is needed before writing the landing

## Landing Copy Mode
Use only when:
- positioning already exists
- offer is mostly clear
- the user mainly needs landing structure and copy direction

## Default
For this project, default to **Fast Track**.
