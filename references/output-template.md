# Output template

Save the final result to a file when working on a real project.
Suggested path: `projects/<agency-name>/positioning-output.md`

---

```markdown
# [Agency Name] — Positioning & Offer Output
Generated: [date]
Mode: [Fast Track / Deep Positioning / Landing Copy Mode]

---

## 1. Business context snapshot
[5-7 line summary: what is sold, for whom, key proof, current gaps]

## 2. Competitive context
[2-3 lines on market landscape, common claims, white space identified]

## 3. Positioning statement
> [Under 30 words. We help [WHO] get [RESULT] through [MECHANISM], unlike [ALTERNATIVE].]

## 4. Target audience
[Who. Job title. Company size. Pain. Budget signal.]

## 5. UTP
[One line. Result + audience + method + differentiator.]

## 6. Offer
**Deliverables:**
- [Deliverable 1]
- [Deliverable 2]
- [Deliverable 3]

**Format:** [retainer / project / workshop]
**Timeline:** [X weeks / months]
**For:** [specific client type]
**Not for:** [anti-customer]
**CTA:** [exact next step]

## 7. Critique score
Total: [X/100]
- Clarity: /20
- Specificity: /20
- Distinctiveness: /20
- Believability: /20
- Commercial pull: /20

Issues found: [list]
Resolved: [list]

## 8. Landing skeleton
### Hero
Headline: [≤12 words]
Subline: [≤25 words]
CTA: [button text]

### Problem
[2-3 bullets]

### Mechanism
[3-5 named steps]

### Offer block
[3-5 bullets]

### Proof
[priority list: case 1, case 2, logos, testimonials]

### Objections
[top 3-5]

### CTA
[primary + secondary]

---
## First draft vs. final
**First draft:** [verbatim if user provided one]
**Final:** [above positioning statement]
**What changed:** [1-2 sentences on what shifted and why]
```
