# Competitor comparison

Goal: prevent the landing from sounding like another generic agency page.

## Research method
Run two parallel searches (use web_search or subagents):

**Search 1 — Direct competitors:**
Find 3-5 agencies solving the same problem for the same client.
For each: positioning claim, pricing signals, key differentiator, visible weakness.

**Search 2 — Adjacent competitors:**
Find 2-3 companies solving a related problem for the same client.
Find 2-3 companies solving the same problem for a different client.
Note: what do they do better? Where is the white space?

After research, ask: "Anything missing or wrong in this competitive picture?"

## Key analysis questions
- What do ALL of them say? (= table stakes, not differentiators — remove from positioning)
- What does NONE of them say? (= potential white space — use this)
- Where does our current draft blend in with them?
- What can we say more narrowly, more outcome-first, more specifically?

## Working rule
Do not require live research if the user has not asked for it.
Use known market patterns unless explicit competitor names are provided.
If real names are available, use them in forced-choice questions (see positioning-workshop.md).

## Output
- Short comparison table
- Common claims to avoid (table stakes)
- White space opportunities
- Where we sound generic
- Recommended differentiation line for the landing
